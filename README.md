# ☀️ SunCart – Summer Essentials Store

## 🌐 Live URL
https://suncart-blue.vercel.app

## 📌 Purpose
SunCart is a modern summer eCommerce platform where users can browse seasonal products like sunglasses, skincare, beach accessories, and summer outfits. Users can view product details and place orders after authentication.

## ✨ Key Features
- 🛍️ Browse summer products
- 🔍 Product details page
- 🔐 Authentication (Login, Register, Google login)
- 👤 User profile with update feature
- 📱 Fully responsive design (mobile, tablet, desktop)
